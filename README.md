# 🚀 Aether Launcher • Next-Gen Minecraft Client

A modern, lightweight, and customizable Minecraft Launcher built with **Python 3** and **PyQt6**. Featuring built-in automatic mod loader installations (Fabric & Forge), Modrinth API integration, dynamic asset generation, and automatic language detection.

---

## ✨ Features

* **Multi-Engine Support**: Easily switch between **Vanilla**, **Fabric**, and **Forge**.
* **Automatic Mod Downloader**: Directly fetches mods from **Modrinth** using project slugs.
* **Auto Language Detection**: Automatically sets UI language based on OS locale (Supports **English** & **Polish** with in-app toggle).
* **Cyberpunk / Neon UI**: Custom dark theme with blurred backgrounds, glow effects, and modern UI elements.
* **Smart Asset Generation**: Automatically generates vector-like icon files (`.ico`) and high-definition background images (`.png`) on first launch.
* **RAM Allocation Control**: Built-in memory slider (`-Xmx` / `-Xms`).
